# NCAAF research preview

`GET /api/research/ncaaf` is a public, mobile-friendly, read-only research page approved for viewing experimental forecasts. `/data` returns the sanitized projection; `/download` downloads the same projection as JSON. No mobile change or OTA is required. It is separate from subscriber Coach; it neither grants entitlement nor bypasses any Coach or simulator validation gate.

The page displays up to the 64 most recently recorded forecast records, sorted by kickoff for display. It shows the exact frozen first-side probabilities, captured bookmaker prices and lines, no-vig two-sided market baseline, push probability, forecast timestamps, model version and input fingerprint. Home is the first side of moneyline/spread; Over is the first side of totals. Results are for that first side. Conditional probabilities exclude pushes. Captured prices are explicitly historical, not current offers. No recommendations, grades, ticket building or confidence claims are generated.

The current candidate has no fitted injury, opponent-strength or venue adjustments. Overtime transfer and release acceptance remain unverified. A displayed game/final is not independent holdout qualification. The 500-distinct-game/two-season acceptance requirement is unchanged. Different model versions are separate records and do not inflate distinct-game counts.

The projector requires a valid pregame chronology, input hash, unchanged quote fields and valid saved probabilities. Team display names come only from a hash-bound source scoreboard matching event, season, teams and kickoff; missing names use explicit ESPN IDs. A final requires an exact forecast fingerprint plus raw final-summary hash, final status, season, event, kickoff, team identities and scores. Scoring reuses saved probabilities and existing exact-line push handling; simulations are never rerun. Unverified finals remain pending and are counted separately. Invalid forecasts are withheld.

The endpoint uses a read-only database transaction with a five-second statement timeout, one coalesced load and a 60-second process cache. It makes no provider requests or database writes. Raw provider responses, athlete rows, availability reports, injury data, internal archive keys and credentials are excluded from the response and download. HTML escapes all source text; CSP disables scripts/frames/forms and indexing is disabled. On database failure it returns 503 rather than invented or stale successful data. Users refresh the page to load newly recorded settlements.

Verification: `node --import ./test/register-hooks.mjs --test test/ncaafResearchPreview.test.ts` from the API directory, API typecheck/build, and a live endpoint smoke test after deployment. Unit cases cover exact preserved probabilities/quotes, input and quote tampering, late records, HTML injection, raw-data exclusion, final fingerprint/source mismatch, pushes and distinct-game counts. Deployment does not change the frozen forecasts, settlement collector or Coach paths.
