# Simulator prop result integrity

The Mobley double-double screenshot showed a 32% hit estimate at +140 but no edge, a separate 54% grading score labeled Confidence, a binary projection of 0, and only a global 10,000 Sims badge. The prop grading lookup matched player/game/side and could borrow another market or line for that player. Edge came only from a provider value-side field, so it could remain absent after simulation or use a different probability basis.

Simulator grading now requires exact game, player, market, numeric line and side, plus matching sport and athlete identities when present. Model edge uses the selected posted price: `(hitProbability - American-price breakEvenProbability) * 100`, in percentage points. Missing/invalid price or probability stays unavailable, including DFS entries without sportsbook odds. At a displayed 32% and +140, price break-even is 41.7% and model edge is approximately -9.7pp. Negative edges remain visible and affect line-value grading. Provider quotes are not changed, and no eligibility floors are relaxed.

Both Simulator and prop-detail screens use the shared presentation helpers. Simulator shows selected odds and price break-even, quality/model scores as scores rather than win probabilities, binary typical outcomes as Yes/No, and actual per-prop simulation/history counts. Prop detail's probability ring uses the prop hit estimate rather than a grading composite; its count caption is no longer hardcoded to 10k. Ordinary counting-stat projections retain their numeric units. A fractional binary probability is not displayed as a projected counting stat or forced to Yes/No.

Shared history fallback helpers now reset simulations to 0, tier to quick and cached to false when replacing an unavailable server result. Empirical fields replace failed server model statistics rather than retaining stale spread/percentiles. A successful server result is preserved without mixing in local confidence/projection fields. History estimates are labeled explicitly; mixed or unavailable prop batches cannot show a blanket 10k badge. Coach's exact-market simulation provenance requirements remain unchanged.

The arithmetic and formatting are local, without any new requests, simulation rounds or background tasks. Tests cover positive/negative prices, invalid inputs, exact market/line/side/athlete matching across eight supported prop sports, binary/count display, quick/deep/mixed/unavailable counts, and empirical fallback count integrity. Release via reviewed preview OTA first, then validate the phone's update identity and actual per-prop evidence before production promotion. These changes do not establish predictive calibration or prove that every posted line has completed grading; Coach's ungraded-line coverage remains a separate diagnostic.
