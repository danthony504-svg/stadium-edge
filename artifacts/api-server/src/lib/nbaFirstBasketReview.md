# NBA First Basket review

The Simulator reads `/sports/nba-first-basket-model`. Without a fresh, exact event lineup confirmation, it displays “Waiting for confirmed starters” and withholds prices. A lineup update that revokes confirmation invalidates the previous projection. The client polls every minute during the final hour before tip and every five minutes earlier.

Configure an isolated backend with `NBA_FIRST_BASKET_CAPTURE` pointing to a trusted JSON file containing `snapshots` and `history` arrays. Use the types in `nbaFirstBasketModel.ts`. The game, team and player IDs must match the Simulator and possession snapshot namespace. Bind provider IDs upstream through a verified crosswalk. Supply confirmed starters, jumpers, full-game per-minute shooting opportunity priors, and timestamped opening possessions containing made and missed attempts. Capture both jump-ball players, tip winner and first possession independently. Treat unknowns as missing. Publish updated files atomically, and include a newer snapshot with `confirmedAt: null` after a scratch until the replacements are confirmed.

The `captureNbaFirstBasket.ts` script accepts trusted lineup snapshots and finalized opening play feeds and emits the normalized file. Inputs contain the opening window only, with complete ordered possessions and explicit possession IDs and teams from the licensed feed adapter. Where the play-by-play supplies a “Tip to” description only, a verified tip winner must accompany the play. The script saves first points and first made field goal separately, including the scoring method, player and game clock.

Use a licensed NBA play-by-play and lineup subscription for production. The capture adapter expects normalized provider output. It does not poll a licensed feed or infer confirmed lineups from recent starters. A verified book rule must be set for each book and market. Quotes come from The Odds API through the event ID in the capture and the existing `ODDS_API_KEY`. Vig is removed for a matched Yes/No pair or a complete mutually exclusive field. Incomplete fields retain posted prices but have no no-vig estimate. Model EV uses the executable posted price.

The priced card uses an opening-possession model and reports posterior probability of positive EV. Thin opening histories can earn at most Lean. The possession review uses the same capture when its five starters per team match the rotation snapshot. It draws the tip and first possession, adjusts opening scoring and shot shares, and records actual first points and first field goals inside the simulation. The two estimates remain separately identifiable.
